# Crescent-Loader

> Crescent moon and star loader in pure CSS

### [View Live Demo](https://fadyehabamer.github.io/css-loaders/Crescent-Loader/)

## Overview

A crescent moon that rocks back and forth while a small star twinkles next to it. The moon is a transparent circle with an offset `box-shadow`, and the star is a `clip-path` polygon, so there are no images at all.

## Built With

**Languages:** HTML · CSS

## Techniques Demonstrated

- Crescent shape from a single `box-shadow`
- Star drawn with `clip-path: polygon()`
- CSS keyframe animations
- `clamp()` sizing through a custom property
- `role="status"` with visually hidden loading text
- `prefers-reduced-motion` fallback that swaps the motion for a slow glow
